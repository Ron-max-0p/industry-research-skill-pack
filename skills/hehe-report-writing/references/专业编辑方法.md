# 专业编辑方法

## 先判断文字的问题在哪里

通读当前任务范围，先回答：给谁看、帮助其理解或决定什么、材料已经支持哪些回答。原文清楚的部分保留。按下表处理真正影响阅读和判断的地方。

| 问题 | 编辑动作 | 完成后的表现 |
|---|---|---|
| 主语和对象不明 | 从上下文找出具体的人、机构、产品、数据或任务，补回句子 | 读者知道谁做什么、针对谁 |
| 名词堆叠 | 把“推进、赋能、闭环、协同”等抽象过程展开为已有材料中的动作与结果 | 例如“核对访谈名单，并确认每位受访者的时间” |
| 只报数字或列材料 | 解释数据差异、相关机制和对当前问题的意义 | 读者知道差异为什么重要 |
| 结论跳跃 | 找到证据到判断缺的环节；已有材料能解释则展开，否则限定该判断或列出具体缺项 | 不用“因此”掩盖没有依据的因果 |
| 前后矛盾 | 对照原表或方案定位冲突，能据原始材料纠正则修正；无法确定时保留给决策者的具体问题 | 不通过模糊措辞消除差异 |
| 段落重复或过度防御 | 合并重复论点；删除仅宣称自己没有犯错的句子 | 有效限制只在影响理解的位置说明 |

专业术语在必要时保留并解释其业务含义。不要建立见词即删的黑名单；“用户留存”“收入确认”等准确概念不必强行口语化。“生态、矩阵、抓手”等词若说不出具体含义，应回到原材料找对象，而非另造术语替换。

## 展开分析，而不是填充篇幅

围绕每个重要问题，把材料组织成读者能跟上的推理：观察到什么 → 如何理解 → 为什么会这样或有哪些可能解释 → 对客户意味着什么。按内容需要展开，不要求每段四句齐全。

解释可以显化输入材料中已经存在的关系，例如同一价格下成本增加使利润空间缩小；新出现的行业归因、用户动机或策略效果需要原材料支持。多种解释尚未区分时，写清最影响决策的分歧与可检验信号。不要为了显得果断把待研究的问题提前定论，也不要因存在缺口撤回已经有依据的发现。

长报告要检查章节间的承接与后半部分深度。删掉模板化收尾后，保留有效案例、解释和对比；摘要压缩正文，正文不缩成摘要。

## 商业表达的完整性

- 建议：针对什么对象、改变什么、为什么优先、依赖什么条件。已有材料含责任和时间时写出；没有则作为建议或待确认，不伪造已商定安排。
- 对比：同一时间、对象和指标含义下比较；若阶段或条件不同，解释差异如何影响判断。
- 金额：收入、毛利、利润、现金流、投资和报价分别使用；税前税后、总额单价、人数人次、人天日历天不得互换。
- 承诺：研究发现、拟议方案、将交付的文件和已经实现的经营效果分别写清。措辞修改不得悄悄改变范围、数量、期限和验收标准。

## 文稿与制作交接

连续正文保持自然的章节、段落和图表解释，模块长度服从内容重要程度。分页文案围绕每页一个主要问题组织信息，必要时拆页。内容页主标题说明对象，副标题必须说明本页故事或核心判断；正文展开依据和解释，结尾不机械复述副标题。

交付前逐项对照必须保留的内容。来源与统计口径可由正文、图注、表头和附录共同承载，移动后仍能定位。将待确认事项集中为简短清单；无待确认事项时不生成空清单。默认交付可用修改稿，重要实质改动再附说明，不向客户展示内部自检过程。
