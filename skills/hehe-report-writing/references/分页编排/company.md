# Company Mode

Use for 企研模块脚本.

## Inputs

Preferred inputs:
- project control file;
- 企研状态卡;
- company list and selection logic;
- company profile notes;
- business model analysis;
- financial data table;
- financing or valuation notes;
- organization and talent notes;
- comparable company matrix;
- source verification notes.

## Page Types

| Page type | Purpose |
|---|---|
| 公司范围页 | Explain company list and selection logic |
| 公司画像页 | Present basic profile and strategic position |
| 业务线页 | Explain products, services, and revenue logic |
| 客户/渠道页 | Show customer groups and go-to-market path |
| 财务经营页 | Show revenue, cost, profit, growth, efficiency |
| 组织人才页 | Explain team or capability when relevant |
| 可比公司页 | Compare companies using consistent dimensions |
| 估值页 | Show valuation only with explicit assumptions |
| 企研小结页 | Hand off to integrated report |

## Evidence Rules

- Public company data must cite report, date, and accounting period.
- Private company data must be marked as estimated, reported by source, or `[待核实]`.
- Valuation output is scenario result, not objective fact.
- Comparable companies require selection logic.
- Do not use product review evidence as company financial evidence.

## Required Output Emphasis

Include:
- company selection boundary;
- data source quality;
- explicit assumptions;
- risks and weak evidence;
- what can and cannot enter PPT.

## Common P0 Blockers

- company list not confirmed;
- financial口径 inconsistent;
- valuation purpose unclear;
- comparable company set not defensible;
- private company numbers treated as facts.
