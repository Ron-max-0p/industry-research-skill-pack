# 句子与段落编辑

专业内容组织完成后，用本表检查具体句子。修改以读者能否准确理解对象、动作与判断为准；不是统计禁词或把正式报告改成聊天。用户提供的风格样例优先决定语气，事实与逻辑仍按专业编辑要求核对。

## 七类编辑动作

| 问题与触发情形 | 怎样改 | 应保留的情形 |
|---|---|---|
| 虚设反驳：先写“不是A而是B”“看似A实则B”，但材料没有提出或检验A | 直接写有依据的B及理由；A若是实质判断，先核对依据，不能借去AI味静默删掉 | 真实备选方案、口径区别、反例或有证据的纠错 |
| 空转提示：反复用“先说结论”“一句话总结”“核心在于”宣布下一句话 | 去掉无信息提示，直接进入判断；保留承接上文所需的对象 | 方法定义、引用、必要分项说明及标题结构 |
| 抽象动作：“完成对……的优化”“构建闭环”没有说清工作 | 从输入找执行者、具体动作和结果，改成直接表达；材料没有细节则保持可确认的含义，集中指出需补什么 | 准确专业术语、必要概括；不把“调整”擅自改成“改善” |
| 概括遮盖数据：同段已有具体数值，仍用“大幅”“显著”重复评价 | 直接给已有变化，再解释业务含义；保留单位、基期、分母及来源 | 无数值但有明确依据的定性判断；统计显著性按原分析使用 |
| 修饰过长：多层限定堆在名词前，读者需回看才找到对象 | 先写对象与动作，再用分句说明条件和作用；保持条件作用范围 | 法律、技术固定表述及读起来清楚的长句 |
| 对象不清或解释空转：“更重要的是”“这说明”没有明确指向，或后文只是重复 | 点明被评论的事实；同义复述合并，新增机制和商业含义展开保留 | 真正推进推理的“因此”“这意味着”等连接；不按词删除 |
| 连续同构：各段都套“数据表明—这说明—因此建议”，案例并排却不解释差异 | 按材料关系安排主次、比较和承接；相同信息合并，独特事实仍保留 | 统一维度比较、执行步骤、并列条款和完整财务科目 |

## 商业报告改写实例

以下是表达示例，具体信息须来自输入材料。

**已有数据优先。**

原文：新流程实现了效率的显著提升。单份审核时间从两小时缩短到四十分钟。

改写：新流程将单份审核时间从两小时缩短到四十分钟。

保留了对象和变化，不据此额外声称审核质量提高或人员成本下降。

**抽象工作写清楚。**

原文：围绕新会员全生命周期开展多维洞察，形成服务优化闭环。

已有材料：研究首次到店、持续到店和停用原因，提出门店服务调整方案。

改写：研究将比较新会员从首次到店到持续使用的经历，分析减少到店和停止使用的原因，并提出门店能够执行的服务调整方案。

材料若仅写了“研究新会员体验”，不能自行补出上述执行范围。

**减少拗口修饰。**

原文：我们将分析那些购买设备后因首次设置复杂而未完成激活的用户所面临的问题。

改写：我们将分析未完成激活的已购用户遇到的问题。这些用户因首次设置复杂而中断激活。

原因来自原文；若原文仅提出可能原因，修改稿也须保留“可能”。

**保留真实解释，删除重复解释。**

原文：续费率由60%降至50%。这说明续费率下降。若获客支出不变，企业需要依靠更多新客户弥补收入缺口。

改写：续费率由60%降至50%。若获客支出不变，企业需要依靠更多新客户弥补收入缺口。

后一判断沿用输入；正式编辑仍核对客单价、收入来源等必要前提，不能只因句子顺畅便认可推理。

## 保留信息与语体

改完对照原材料，检查对象、数据、来源、条件、因果和判断强度。允许换词、调整语序与合并重复信息，不要求每个词都在原文出现。材料已有的具体内容可以重新组织，未经支持的事实和承诺不能补入。

章节编号、主副标题、完整清单、表格和图注按交付用途保留。PPT内容页仍是主标题说明对象、副标题说明故事；主标题中的连接符不作为去AI味对象。采集、存储、展示三个必要环节应逐项保留；“只关注”与“首先关注”含义不同，不能互换。

保留实际时间或条件关系，例如“当试点通过验收时再扩大投入”。必要的否定、转折、冒号、长句及专业名词按作用判断，不按数量或句长门槛改写。直接引文保持原文；不以强加人称、语气词或故意变化句长制造人味。

完成标准：读者更容易理解，独特信息和分析深度保留，商业含义及判断强度准确。检查工具如被使用，仅提示候选问题；命中数不作为AI味评分，也不直接批量改写。
