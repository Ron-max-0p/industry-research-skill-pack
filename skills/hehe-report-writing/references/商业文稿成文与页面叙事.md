# 商业文稿成文与页面叙事

用于计划书、研究报告及逐页文案的写作和实质修改。先明确交付对象与用途，再组织文字。商业表达的成熟度体现在对象准确、论述完整、方法有针对性、判断可使用，不以术语数量或句子长短衡量。

## 与一般行文的区别

一般文章可以围绕见闻、感受或主题展开；商业文稿承担明确的沟通任务，使读者形成判断、选择方案或确认合作。每一部分都要让读者看见其用途。

| 层次 | 商业文稿的具体要求 |
|---|---|
| 对象 | 明确企业、业务、产品、人群、地区和阶段；同一称谓始终指向同一主体 |
| 论述 | 将背景、问题、研究动作、依据与业务用途连接起来，不能只罗列名词 |
| 判断 | 区分研究发现、拟议方案和交付承诺，明确影响选择的条件 |
| 语言 | 用准确业务概念和完整陈述传递信息；语气专业、具体、自然 |
| 组织 | 每页有明确作用，同章逐层展开，整篇支持同一研究或商业任务 |

“梳理、比较、识别、评估、测算、提出”后面应有具体对象；“支持、用于、为……提供依据”后面应有具体决定。不能只把“了解”替换成“洞察”便视为专业化。按材料表达实质，不要求句句套用同一语法。

## 先确定页面对客户的作用

写作时为每页明确一个主要沟通任务。这是内部编排依据，不是必须展示给客户的标签。

| 页面任务 | 应呈现的实质内容 | 对读者的价值 |
|---|---|---|
| 展示需求理解 | 委托方背景、业务目标、当前问题、具体需求及待作决定 | 看见研究团队理解的是本项目，而非通用模板 |
| 展示研究方案 | 问题拆解、方法选择、模块关系、预期回答及适用条件 | 判断方案的针对性、研究深度和可执行性 |
| 展示研究能力 | 方法、人员、资料或执行资源如何支持本题 | 判断服务方是否具备完成工作的条件 |
| 展示相关经验 | 过往任务、承担工作、产出及与本题的对应关系 | 理解已有经验可以怎样应用于本项目 |
| 展示资质与奖项 | 已核实的名称、授予机构、时间及所代表的能力 | 提供信任依据；资质不替代本题解决方案 |
| 解释研究发现 | 发现、关键证据、差异或机制、业务意义 | 支持读者理解现状及调整选择 |
| 说明执行安排 | 阶段、具体工作、日期、双方任务及确认成果 | 理解如何推进合作 |
| 说明交付成果 | 交付内容、形态、用途及验收要求 | 知道最终获得什么、如何使用 |
| 说明商务报价 | 工作范围、数量、单价、费用与付款条件 | 评估采购安排，报价可独立抽取 |

经验、奖项与能力使用已有真实材料；没有资料时不虚构履历或把其他机构的案例当作自身经验。方案的专业态度通过清楚的需求理解、详实设计与一致承诺体现，不靠自称“严谨、专业、经验丰富”。

## 单页表达完整，主副标题与正文一致

内容页主标题说明本页对象和分析角度；副标题用完整陈述表达本页故事或核心判断；正文与图表提供展开和依据。标题及正文使用陈述句。

将页面单独抽出，目标读者应能识别讨论对象、主要意思和对自己的用途。必要的企业、产品、人群及研究范围要写在本页合适位置，不依赖封面才能猜出。无需每页复述全部背景，具体名称、图表标签和简短范围说明可共同完成定位。“本品、竞品、三类人群、现有试用”等简称须在本页有明确对应；首次介绍一项既有研究应交代谁参加、测试什么、在哪里发生，再讨论其结果。

先写清本页要传达的完整意思，再安排标题、图形与卡片。信息卡标题要标识具体业务内容，不能只有“补齐判断、形成解释、经营选择”等动作。字号和版面不足时调整布局或拆页，不能删掉产品、市场、人群及关系词，使文字只剩作者自己懂的提示。

一页围绕一个主要沟通任务，可以包含数项共同支持该任务的内容。例如项目总览可串联需求、方法与成果；多种方法也可共同说明研究思路。交付物和报价承担不同任务，应分开；内部成本测算、资料索取不混入需求理解页。

检查标题、表头、段落、图表是否在解释同一件事。主标题写市场规模，副标题与正文就应解释市场规模的对象、测算或判断；预算、甲方配合要求不能因版面有空位便塞入。表格各列准确命名：建议写推荐采取的选择，交付物写实际材料，条件写成立前提，资料写具体输入，不能混为一列。

## 丰富而清楚的商业用语

完整句子用于交代背景、解释关系、陈述判断和说明方案。保留必要主语、对象、动作、范围和结果，使读者不必自行补全逻辑。信息卡标题即使较短，也应形成意思完整的陈述，说明具体对象及本卡要表达的意思；不能用“需求验证、投入边界”等名词替代。坐标、图例、表头和章节名可用准确名称；正文、副标题及解释性信息卡不能靠多个短语拼接代替完整表达。

例如“选客群、选产品、选路径、作决定”只能作流程标签。正文应进一步交代：比较哪些客群的哪些需求，如何匹配企业能力，比较哪些销售服务方式，最终支持什么经营决定。

同样，“市场机会识别”可作模块名；本模块的方案说明应写清研究对象、比较或测算内容及用途。长句如已准确表达一组连贯关系，可以保留；确实难读时按逻辑拆句，不删除关键条件。页面容纳不下，应调整编排或拆页，不压缩成残缺短句。

## 先成文，再分页，最后排版

计划书和商业报告需要完整解释背景、分析和方案。先写成读者能理解的正文，再按主要沟通任务分配页面，最后选择表达内容关系的版式。不预设每页几张卡片、每卡几行，也不以互联网信息卡的短句密度作为报告标准。

正文可以包含充分的段落；字数随解释需要确定。删除重复和无信息修饰，保留对象、条件、关系及推理。主标题定位主题，副标题说明故事，正文展开论述，图注说明口径，各层不争夺同一视觉强度。重要内容用位置、比例、字号及适度强调体现，不把所有句子都放大加粗。

分页稿交给呈现时保留原文对应位置与必须保留的解释。排版装不下时，先调整图文比例和构图，再按完整问题拆页；只删真正重复的内容。布局修改后复查主语、条件和推理是否保留，不能以“适合PPT”为由把段落削成提示词。

## 前后页面形成连续叙事

计划书通常从业务处境与目标进入需求理解，再展示研究思路、方法、成果及执行安排；能力和经验页放在最能支持方案可信度的位置。成果报告通常从核心发现进入证据、解释、影响与建议。顺序按本题和既定模板选择，不强制所有报告使用相同目录。

按三个层次核对整份文稿：

1. 顺读主标题，研究对象与章节分工清楚。
2. 顺读副标题，能够理解背景、问题、方案或发现如何逐步展开。
3. 回到正文，确认每页充分支持副标题，上一页提供下一页所需的前提，没有突然切换对象或混入其他任务。

副标题串联不是给每页加“首先、其次、最后”。需要的是实质关系：前页界定需求，后页拆解任务，再说明研究能够形成的回答；前页展示变化，后页解释机制，再讨论影响。局部结论不充分时补足材料内的解释，不用过渡套话掩盖断点。

## 改稿对照与验收

| 旧表达的问题 | 成熟商业文稿的处理 |
|---|---|
| “八周内明确首批客户”未交代谁的哪项业务 | 写清委托方拟进入的产品业务、目标采购群体、区域和项目用途 |
| 需求章列资料提交和预算 | 先说明需求及研究价值；资料协作与报价分别归位 |
| “研究与咨询成果”一列混合方法、建议和材料 | 分清研究动作、可形成的判断及交付物，用准确列名对应 |
| 每页孤立，副标题是半句话 | 用完整副标题讲清页面故事，检查前后推理关系 |
| 能力页只有“丰富经验” | 用已有案例或资源说明与当前任务的相关性和支持方式 |

交付前分两遍检查：

1. **单页脱离上下文阅读。** 只依据本页标题、正文和图表，复述谁的什么业务或产品、针对什么人群或市场、本页说明什么、读者据此理解或决定什么。复述需要补入聊天记录或其他页面的信息，就把缺少的内容写回本页。只在内部写“页面用途”不算完成，页面本身须表达出来。
2. **整章顺读。** 依次读副标题和正文，确认背景已经导出明确研究目标，各项研究对应目标，前后页面有实质联系。发现汇报日期混入研究思路、预算混入需求等情况，移回所属章节。

这两遍检查先于排版验收；页数、禁词命中数、无溢出及金额正确不能证明内容合格。自查记录只简述实际发现和修改，不自称读者已认可，也不虚构独立评审。修复问题后交付正文，内部检查话术不写进客户报告。
