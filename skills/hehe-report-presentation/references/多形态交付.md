# 多形态交付与阅读样式

## 选择形态

| 形态 | 使用场景 | 编排方式 | 导出 |
|---|---|---|---|
| 16:9 横版 | 客户会议、咨询汇报、桌面阅读 | 横向比较、图表与解释、完整主题同页；1280×720 | 一页对应一页，16:9 PDF；可编辑 PPTX |
| 9:16 竖版 | 手机翻页阅读 | 720×1280；以单列论述、纵向过程为主，复杂比较表按完整维度分组 | 一页对应一页，9:16 PDF；分页源可转 PPTX |
| A4 竖版 | 正式阅读、打印、批注 | 794×1123；段落、表格与页内小标题，控制过宽长行 | 210×297mm PDF；分页源可转 PPTX |
| 下拉 HTML | 长报告、在线查阅 | 自然高度，按内容重要性安排模块，目录定位；窄屏重排 | A4 自然分页 PDF；PPT另做分页源 |

竖版先放置完整主题，再检查实际高度。横向流程在竖版改为纵向步骤或有清晰先后顺序的分行；同维度表格仍保留列关系。多列宽表若确实不适合竖版，按比较维度拆成主题明确的页面，保留对象、表头与来源。改动页数后重建目录和引用。

下拉版直接接收 Markdown 或已有结构化内容，不要求分页脚本，也不为每节补造副标题。桌面侧栏按实际章节和小节生成目录，支持跳转及当前位置提示；窄屏使用折叠目录。长论述保持连贯，图表和解释可并排，移动端按阅读顺序上下排列。屏幕上的模块数量不决定打印页数；打印隐藏侧栏与操作栏，正文恢复全宽，按 A4 自然分页，检查页尾孤立标题、表格续页和图形裁切。

## 三种基础阅读样式

| theme | 风格 | 使用重点 |
|---|---|---|
| blue | 深蓝、白底、青色强调 | 正式研究建议书和咨询报告；沿用已确认蓝白体系 |
| editorial | 暖白、墨绿、宋体标题、较轻表头 | 长篇研究解读和阅读型报告，强化段落层级 |
| brief | 蓝灰、暖金标记、紧凑页眉 | 管理层讨论和多表格分析，突出对象与比较轴 |

它们是可组合的阅读样式，不代替版式设计。相同内容关系使用稳定结构，不同关系采用适配的流程、矩阵、结构图或分析图表。品牌要求优先；只修改样式变量不能算完成整稿美化。

### 蓝白16:9封面与章节页

使用 `assets/cover_chapter.json` 作为完整示例，样式已包含在 `assets/modes.css` 中。封面采用深蓝底、左侧完整主副标题、委托对象和日期、右侧低对比主题线稿；章节页采用浅底、左侧深蓝编号栏、右侧章标题与说明，下方列出本章研究任务。

后续同风格报告保留配色、主次关系和版式，替换项目名称、正文及编号；主题线稿按行业更换，研究任务按实际章节填写。其他画布使用对应布局；指定品牌模板时遵循品牌要求。

## 标题与完整文字

正文有效空间由实际主副标题高度决定。标题发生孤立单字换行时，优先在完整词组或主题边界插入换行、调整标题宽度和周边布局。流程标签和日期列保留完整词组。正文留出合理行距，不把句末单字、标点或条件单独挤到下一行。

内容少且主题已完整时，用适当行长和位置建立稳定阅读区域。内容连续且同属一个主题时，合并页面优于放大字体；合并仍要让读者看清本页主要意思。
