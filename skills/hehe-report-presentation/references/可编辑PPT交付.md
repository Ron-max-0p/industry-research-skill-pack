# 可编辑 PPT 交付

## 实现路径

采用同一页面源先排版 HTML，再将浏览器计算得到的几何位置映射为 PPT 原生对象。这样可以共享内容与版式，又让文字、表格、矩形、线条和有数据的图表保持可编辑。

`scripts/export_pptx.py` 适用于本 Skill 生成的分页 HTML。它读取真实布局，不使用整页截图。下拉文稿先按完整主题制作分页源；任意外部网页、复杂网页组件及动画不在该脚本的通用转换范围内。

新制作或美化的报告先在 HTML 生成时通过 [图形方案检查](图形优先与生成检查.md)，再导出 PPT；各图式的可编辑程度仍按下表验收。历史 HTML 的格式转换保留原有路径，不据此宣称已重新完成视觉设计。

| 页面内容 | PPT 中的形式 | 检查方式 |
|---|---|---|
| 标题与正文 | 原生文本框，保留字号、字色和基本字重 | 改文字、保存、重开；中文字体显式设置 |
| 比较表 | 原生表格 | 改一个单元格并重开；核对行高、列宽和换行 |
| 背景块、线条、流程箭头及表内数值底色条 | 原生形状 | 移动或改变大小后重开；表内色条与数值分别编辑 |
| `chart` 组件 | 带嵌入数据工作簿的原生图表 | 修改系列数据，验证图形随数据变化 |
| SVG 插图 | 独立图片 | 可移动和替换；图片内部路径不逐点编辑 |

原生图表支持柱形、折线、堆积、横向条形和瀑布。瀑布由可编辑的堆积图表及浮动基数构成；修改增减额时需同步调整后续浮动基数、合计及带符号标签，或修改页面源重新生成。使用明确数据生成的图表才进入原生图表路径。复杂合并单元格当前需要在页面源展开或另写原生表格处理。SVG保留画布内可见部分，转换清单列明独立图片。目录转为幻灯片跳转，来源保留链接；逐页实渲染核对字体、换行、链接颜色和图表读数。

## 命令

```text
python scripts/export_pptx.py 报告_CO.html 报告_CO.pptx --browser "本机Chromium或Chrome的路径"
```

运行前按 [依赖清单.md](../依赖清单.md) 准备对应环境；生成依赖与实际编辑验收软件分别列明。输出旁的对象核验 JSON 列出各页原生文本框、表格、图表与图片数量。

## 实际编辑验证

先用 PowerPoint 或 LibreOffice 打开生成文件，观察是否出现修复提示，再导出 PDF 或页面图片。选实际存在的文字、表格、图表、流程对象，在独立测试副本修改并重开；确认修改被保存且相关图表更新。检查完整正文、图例、单位、来源、页脚及遮挡。技术数量证明对象类型，实际打开和渲染证明交付结果。

页面源是内容与样式的共同维护入口。为稳定中文排版，转换时保留浏览器中的软换行；文字仍在完整文本框或表格单元中。增加文字后可调整框宽或换行位置，再查看实际页面。

用户直接修改 PPT 后，以用户新版为准；重新生成前先读回这些改动，不覆盖已经确认的修改。
